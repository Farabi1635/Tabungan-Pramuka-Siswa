# Tabungan Pramuka – SMP Mangun Jaya 01
Web App PWA (HTML/CSS/Vanilla JS, Local Storage) untuk satu regu Pramuka.
**Cara jalan:** buka folder di VS Code → klik kanan `index.html` → *Open with Live Server* → buka di HP Android (satu Wi-Fi) → menu Chrome → *Tambahkan ke layar utama*.
- Saldo selalu dihitung dari transaksi (bukan disimpan manual).
- Logo: tunas kelapa (`logo-pramuka.png`) dan lambang Pramuka dunia (`logo-pramuka-dunia.png`).
- Grafik memakai Chart.js lokal (`assets/js/chart.umd.js`), jalan offline.
- Backup rutin lewat Pengaturan → Backup JSON.
